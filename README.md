# Isaac-RL

/goal Build a RL agent that learns to play The Binding of Isaac from scratch. Create a bridge that streams game state to Python and sends agent actions back. Design and implement a RL architecture: environment, observation space, action space, reward function, algorithm, and training loop. Add a live terminal showing episode count, reward, and loss to track progress. The goal is complete when the agent can consistently clear the first floor, including the boss.

First Steer: look to have parallel processes
